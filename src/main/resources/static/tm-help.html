Užklausos formos pildymo paaiškinimai

(540) Prekės ženklas / Trade mark -

Paieška vykdoma pagal žodį arba žodžio dalį esančio:

  • Prekės ženklo pavadinimo pradžioje - (prasideda / begins)
  • Prekės ženklo pavadinimo pabaigoje - (baigiasi / ends)
  • kitoje Prekės ženklo pavadinimo vietoje - (turi / contains)

Paieška taip pat vykdoma pagal tikslų Prekės ženklo pavadinimą - (yra / is)

Toks principas taikomas ir kitiems formos laukams

(210) Paraiškos numeris / Application number

Paraiškos numeriai gali būti kelių tipų:

  • RL XXXXX
    ZP XXXXX
     
  • 95-XXXXX
    99-XXXXX
     
  • 2000 XXXXX
    2002 XXXXX

(kur XXXXX bet koks skaičius)

(111) Registracijos numeris / Registration number

Skaitmeninis simbolis (skaičius)

(511) Prekės ir paslaugos / Goods and Services

Indeksai / Indication - bet koks skaičius nuo 1 iki 45

Sąrašas / List - Paieška vykdoma pagal žodį, žodžio dalį arba pagal tikslų pavadinimą (taip pat kaip lauke 540 ir kitur)

(531) Tarptautinės ženklų vaizdinių elementų klasifikacijos indeksai/Indication of International Classification of the Figurative Elements of Marks

Pvz.: 27. arba 9.5 arba 5. arba 1. ir panašiai

(opposinr) Protesto numeris / Opposition number

Protesto numeriai gali būti :

  • PNZ-nnn nacionalinis
  • PTZ-nnn tarptautinis

(kur nnn bet koks skaičius)

(invinr) Negaliojimo prašymų numeris / Invalidation number

Negaliojimo numeriai gali būti :

  • PNNZ-nnn nacionalinis
  • PNTZ-nnn tarptautinis

(kur nnn bet koks skaičius)

(invinr) Panaikinimo prašymų numeris / Cancellation number

Panaikinimo numeriai gali būti :

  • PPNZ-nnn nacionalinis
  • PPTZ-nnn tarptautinis

(kur nnn bet koks skaičius)

(appealnr) Apeliacijos numeris / Appeal number

Apeliacijos numeriai gali būti :

  • ANZ-nnn nacionalinis
  • ATZ-nnn tarptautinis

(kur nnn bet koks skaičius)

(dtdecision) Sprendimo data / Decision date

Datos formatas:

  • YYYY-MM-DD

Pvz. 2013-01-01

(decisnr) Sprendimo numeris / Decision number

Skaičius, pvz. 1382

(descdecision) Žodžiai tekste / Text search :

Pavyzdžiai/Examples :

(turi / contains) moksliniai ir pramoniniai tyrimai
